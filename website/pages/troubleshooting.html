Troubleshooting

The installer and npm run setup print a fix for every known problem. This page collects them in one place.

"devChat needs Node.js 26 or newer"

  • Windows: winget install OpenJS.NodeJS.LTS, then open a new PowerShell window.
  • macOS: brew install node
  • Linux: nvm install 26 (install nvm from github.com/nvm-sh/nvm)

Check with node --version. It must print v26 or higher.

npm install fails

  • Check your internet connection, VPN or proxy, then rerun the installer. It updates the existing folder instead of starting over.
  • Do not use sudo npm. If npm reports permission errors, install Node.js with nvm or winget as shown above.
  • Behind a company proxy: npm config set proxy http://proxy:port and npm config set https-proxy http://proxy:port.

WhatsApp: Chrome download fails

WhatsApp runs through a headless Chrome. If downloading Chrome is blocked on your network, use a Chrome that is already installed:

# macOS / Linux
PUPPETEER_SKIP_DOWNLOAD=1 npm run setup -- --messenger whatsapp
export PUPPETEER_EXECUTABLE_PATH="/usr/bin/google-chrome"
npm start
# Windows PowerShell
$env:PUPPETEER_SKIP_DOWNLOAD="1"; npm run setup -- --messenger whatsapp
$env:PUPPETEER_EXECUTABLE_PATH="C:\Program Files\Google\Chrome\Application\chrome.exe"
npm start

"[WhatsApp] is not installed yet"

The WhatsApp driver is installed by setup, not by npm install. Run npm run setup again; it only installs what is missing.

The QR code is unreadable in the terminal

Use the browser link printed under it (https://devchat-docs.vercel.app/qrcode/…). The code is drawn in your browser. Or make the terminal window wider, or use a font with square characters.

The bot logs in but does not reply

  • Send messages from a different account. Bots ignore their own messages by default.
  • In group chats, the starter bot only answers when it is @-mentioned (requireMentionInRoom: true).
  • If you spam it, the rate limiter pauses replies for a minute. This is intended.
