Frequently asked questions

What is devChat?

devChat is an open-source chatbot SDK for TypeScript and Node.js. It gives you one API for many messengers, plus built-in command routing, auto-replies and rate limiting. It is a fork of Wechaty.

Which messengers are supported?

Any messenger with a Wechaty puppet provider, including WeChat, WhatsApp, WeCom, Lark/Feishu, QQ and Gitter. See Puppet providers.

Which Node.js version do I need?

Node.js 26 or newer, with npm 10 or newer. devChat runs its .ts sources directly on Node.js.

Can my account get banned?

Unofficial protocols carry risk. Reduce it by using rate limits (rateLimit in both plugins), by not mass-messaging people, and by using an official or paid puppet for production.

How do I test a bot without a real account?

Use wechaty-puppet-mock. devChat's own plugin tests drive a real bot this way:

import { PuppetMock } from 'wechaty-puppet-mock'

const puppet = new PuppetMock()
const bot    = DevChatBuilder.build({ puppet })
const me     = puppet.mocker.createContact({ name: 'Bot' })
const user   = puppet.mocker.createContact({ name: 'User' })

await bot.start()
await puppet.mocker.login(me)
user.say('/ping').to(me)   // your handlers receive this message
