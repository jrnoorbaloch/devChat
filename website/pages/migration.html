Migrating from Wechaty

devChat is a fork of Wechaty and keeps its API, so most bots move over by changing one import.

Steps

  1. Replace the dependency: remove wechaty and install devChat (see Getting started).
  2. Change imports from 'wechaty' to 'devchat'.
  3. Optionally rename to the devChat brand names (DevChatBuilder, DevChat, DevChatPlugin).
  4. Optionally rename environment variables from WECHATY_* to DEVCHAT_*.
- import { WechatyBuilder } from 'wechaty'
+ import { DevChatBuilder } from 'devchat'

- const bot = WechatyBuilder.build()
+ const bot = DevChatBuilder.build()

What stays the same

  • All Wechaty* exports (WechatyBuilder, Wechaty, WechatyPlugin, …).
  • All wechaty-puppet-* providers and community plugins.
  • Events, user modules (Contact, Room, Message, …) and their methods.
  • WECHATY_* environment variables. If both a DEVCHAT_* and a WECHATY_* variable are set, the DEVCHAT_* one wins.
