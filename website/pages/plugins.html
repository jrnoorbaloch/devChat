Built-in plugins

devChat ships three plugins for the jobs almost every bot needs. They are plain functions, so you can mix them with your own on('message') handlers and any Wechaty-compatible plugin.

import { CommandRouter, AutoReply, RateLimiter } from 'devchat'
// or: import { CommandRouter } from 'devchat/plugins'

CommandRouter

Routes messages that start with a prefix (default /) to named handlers. Whatever a handler returns is sent back as the reply.

bot.use(CommandRouter({
  commands: {
    ping: () => 'pong',
    echo: {
      description: 'Repeat your text',
      aliases: ['say'],
      handler: ({ rawArgs }) => rawArgs || 'Usage: /echo <text>',
    },
    remind: async ({ args, message }) => {
      const [minutes, ...text] = args
      setTimeout(() => message.say(`⏰ ${text.join(' ')}`), Number(minutes) * 60_000)
      return `OK, I will remind you in ${minutes} min.`
    },
  },
  rateLimit: { limit: 10, intervalMs: 60_000 },
  requireMentionInRoom: true,
  unknownReply: 'Unknown command /{command}. Try /help.',
}))

Argument parsing

Arguments are split on whitespace. Single or double quotes group words together:

MessagecommandargsrawArgs
/pingping[]''
/todo add "buy milk" nowtodo['add', 'buy milk', 'now']add "buy milk" now

The same parser is exported as parseCommand(text, prefix).

AutoReply

Answers messages that match declarative rules. Rules are checked in order and only the first match replies, unless you set firstMatchOnly: false.

bot.use(AutoReply({
  rules: [
    // whole message, case-insensitive
    { match: 'hi', reply: 'Hello! 👋' },
    // substring
    { match: 'pricing', contains: true, reply: 'Plans start at $9/month.' },
    // RegExp – the match is passed to the reply function
    { match: /weather in (\w+)/i, reply: (_msg, m) => `Checking weather for ${m?.[1]}…` },
    // any predicate
    { match: text => text.endsWith('?'), reply: 'Good question! A human will answer soon.' },
  ],
  rooms: true,
  requireMentionInRoom: true,
  rateLimit: { limit: 5, intervalMs: 60_000 },
}))
Rate limits in AutoReply only count messages that matched a rule, so normal chatter never uses up a user's quota.

RateLimiter

The sliding-window limiter the plugins use is exported for your own handlers:

const limiter = new RateLimiter({ limit: 3, intervalMs: 10_000 })

bot.on('message', async message => {
  if (!limiter.tryAcquire(message.talker().id)) return
  // ... expensive work, e.g. calling an LLM
})

Methods: tryAcquire(key), remaining(key), reset(key?).

Writing your own plugin

A plugin is a function that receives the bot and may return an uninstaller:

import type { DevChatPlugin } from 'devchat'

export const Logger = (): DevChatPlugin => bot => {
  const onMessage = (m) => console.log('[msg]', m.text())
  bot.on('message', onMessage)
  return () => bot.off('message', onMessage)
}

bot.use(Logger())
