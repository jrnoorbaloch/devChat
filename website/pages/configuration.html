Configuration

Configure devChat with builder options in code, or with environment variables for deployments.

Builder options

const bot = DevChatBuilder.build({
  name: 'support-bot',              // also used for the session file name
  puppet: 'wechaty-puppet-wechat4u',
  puppetOptions: { /* passed to the puppet */ },
})

Use DevChatBuilder.singleton(options) when your whole process should share one bot.

Environment variables

Every setting has a DEVCHAT_ name. The legacy WECHATY_ name still works. If both are set, DEVCHAT_ wins.

VariableLegacy namePurpose
DEVCHAT_PUPPETWECHATY_PUPPETPuppet provider package name
DEVCHAT_TOKENWECHATY_TOKENToken for puppet services
DEVCHAT_NAMEWECHATY_NAMEBot name / session file
DEVCHAT_PORTWECHATY_PORTHTTP port (PORT takes priority)
DEVCHAT_PUPPET_SERVICE_IPWECHATY_PUPPET_SERVICE_IPFixed IP of a puppet service
DEVCHAT_APIHOSTWECHATY_APIHOSTAPI host for the IO client
DEVCHAT_DEBUGWECHATY_DEBUGEnable debug mode
DEVCHAT_DOCKERWECHATY_DOCKERSet when running inside Docker
WECHATY_LOG—Log level: silly, verbose, info, warn, error

Read settings the same way in your own code with envSetting('PUPPET').

Puppet providers

A puppet is the driver that connects devChat to a messenger. Install the one you need, then select it:

MessengerPuppet package
WeChat (web protocol, default)wechaty-puppet-wechat4u
WeChat (browser)wechaty-puppet-wechat
WeChat (iPad protocol)wechaty-puppet-padlocal
WhatsAppwechaty-puppet-whatsapp
Lark / Feishuwechaty-puppet-lark
Gitterwechaty-puppet-gitter
QQwechaty-puppet-oicq
WeChat Official Accountwechaty-puppet-official-account
Remote puppet servicewechaty-puppet-service
Testingwechaty-puppet-mock
 
npm install wechaty-puppet-whatsapp
DEVCHAT_PUPPET=wechaty-puppet-whatsapp node bot.ts

Run npm run puppet-install to install all official puppets. npm run doctor checks your environment.

Docker

docker build -t devchat .
docker run -it --rm -e DEVCHAT_PUPPET=wechaty-puppet-wechat4u \
  -v "$PWD":/bot devchat bot.ts
