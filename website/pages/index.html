devChat keeps the battle-tested Wechaty core and adds the pieces every bot ends up rewriting by hand.

A useful bot in 20 lines

Plug in the built-in CommandRouter and AutoReply plugins, choose a messenger with DEVCHAT_PUPPET, and start.

Read the plugin guide →

import { DevChatBuilder, CommandRouter, AutoReply } from 'devchat'

const bot = DevChatBuilder.build({ name: 'my-bot' })

bot.use(
  CommandRouter({
    commands: {
      ping: () => 'pong',
      echo: ({ rawArgs }) => rawArgs,
    },
    rateLimit: { limit: 10, intervalMs: 60_000 },
  }),
  AutoReply({
    rules: [{ match: 'hi', reply: 'Hello! Type /help' }],
  }),
)

bot.on('scan', qr => console.log('Scan:', qr))
await bot.start()
