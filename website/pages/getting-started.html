Getting started

Run your first devChat bot in a few minutes. You need Node.js 26 or newer and npm 10 or newer.

1. Get the code

devChat is not on npm yet. Until it is, clone the repository and install its dependencies:

git clone https://github.com/jrnoorbaloch/devChat.git
cd devChat
npm install
To use devChat inside another project, build and pack it once with npm run dist && npm pack. Then run npm install /path/to/devchat-<version>.tgz in your project and import { DevChatBuilder } from 'devchat'.

2. Run an example bot

# minimal "ding → dong" bot
npm run demo

# command bot with /ping, /echo, /roll, /time and /help
npm run demo:commands

The bot prints a QR code in your terminal. Scan it with the messenger account the bot should use. Once you are logged in, send /help to the bot from another account.

3. Write your own bot

Create bot.ts. Node.js 26 runs TypeScript directly, so there is no build step:

import { DevChatBuilder, ScanStatus, CommandRouter } from 'devchat'

const bot = DevChatBuilder.build({ name: 'my-first-bot' })

bot.use(CommandRouter({
  commands: {
    ping: () => 'pong',
    hello: ({ args }) => `Hello, ${args[0] ?? 'friend'}!`,
  },
}))

bot
  .on('scan', (qrcode, status) => {
    if (status === ScanStatus.Waiting) {
      console.log('Scan this QR code to log in:', qrcode)
    }
  })
  .on('login',  user => console.log(`${user.name()} logged in`))
  .on('logout', user => console.log(`${user.name()} logged out`))
  .on('message', async message => {
    console.log(`${message.talker().name()}: ${message.text()}`)
  })

await bot.start()
node bot.ts

4. Understand the lifecycle

StepWhat happensEvent
bot.start()Loads the puppet (messenger driver) and connectsstart, puppet
ScanA login QR code is generatedscan
LoginThe account is logged in; bot.currentUser is setlogin, ready
ChatEvery incoming and outgoing messagemessage
bot.stop()Disconnects and releases resourceslogout, stop

5. Choose a messenger

devChat talks to messengers through puppets. The default is wechaty-puppet-wechat4u (WeChat web protocol). Pick a different one with an environment variable:

DEVCHAT_PUPPET=wechaty-puppet-whatsapp node bot.ts

See Configuration for every setting and the list of supported puppets.
