Sending messages

Anything "sayable" can be sent with say(): text, files, contacts, links and more.

import { FileBox } from 'file-box'

await message.say('Plain text')
await message.say(FileBox.fromUrl('https://example.com/report.pdf'))
await message.say(new bot.UrlLink({ url: 'https://github.com/jrnoorbaloch/devChat', title: 'devChat' }))

// mention people in a room
const room = message.room()
if (room) await room.say`Hi ${message.talker()}, welcome!`

Contacts and rooms

const alice   = await bot.Contact.find({ name: 'Alice' })
const friends = await bot.Contact.findAll()
await alice?.say('Hello Alice')

const room = await bot.Room.find({ topic: 'devChat users' })
await room?.say('Release 2.0 is out 🎉')
await room?.add(alice!)
const members = await room?.memberAll()
