Getting started

One command installs everything, asks which messenger you want (WeChat, WhatsApp or both), and creates a working bot.

1. Install

Windows (PowerShell)

irm https://raw.githubusercontent.com/jrnoorbaloch/devChat/main/install.ps1 | iex

macOS and Linux

curl -fsSL https://raw.githubusercontent.com/jrnoorbaloch/devChat/main/install.sh | bash

The installer:

  1. checks for Git, Node.js 26+ and npm. If something is missing it offers to install it, and always asks first: Git and Node.js with winget on Windows, Node.js with nvm on macOS/Linux. On macOS/Linux, Git is not installed automatically; the installer shows the command for your system;
  2. downloads devChat into a devChat folder;
  3. installs the dependencies;
  4. asks which messenger you want and installs only what that choice needs.
Which messenger do you want your bot to use?
  1) WeChat
  2) WhatsApp
  3) Both
Enter 1, 2 or 3 [1]:
WhatsApp downloads a headless Chrome browser the first time, about 150 to 200 MB. Choosing only WeChat skips that download.

2. Start your bot

cd devChat
npm start

The devChat dashboard opens in your browser at http://localhost:3000 and shows the login QR code:

Scan it with the phone of the account the bot should use:

  • WhatsApp: Settings → Linked devices → Link a device
  • WeChat: tap + → Scan

The card switches to Connected by itself. The dashboard then shows the logged-in account, message counts, a Log out button and a live feed of messages:

Now send /help to the bot from another account. The dashboard only runs on your computer, and you can close the tab while the bot keeps running. Stop the bot with Ctrl+C in the terminal.

3. Make it yours

Your bot lives in bot.ts. The same code runs on every messenger you picked:

import { AutoReply, CommandRouter, startDevChat } from './src/mods/mod.ts'

await startDevChat({
  setup: (bot, messenger) => {
    bot.use(
      CommandRouter({
        commands: {
          ping: () => 'pong',
          hello: ({ args }) => `Hello, ${args[0] ?? 'friend'}!`,
        },
      }),
      AutoReply({ rules: [{ match: 'hi', reply: 'Hello! 👋' }] }),
    )
    bot.on('message', m => console.log(`[${messenger}] ${m.text()}`))
  },
})

Save the file and run npm start again. See Plugins for everything CommandRouter and AutoReply can do.

4. Switch messengers later

npm run setup                          # asks again
npm run setup -- --messenger both      # no question

Your bot.ts is kept. The choice is saved in devchat.config.json.

Manual install (developers)

git clone https://github.com/jrnoorbaloch/devChat.git
cd devChat
npm ci
npm run setup

For CI or Docker, every question has a flag: npm run setup -- --messenger whatsapp --yes, or set DEVCHAT_MESSENGERS=both. A plain npm install never asks anything.
