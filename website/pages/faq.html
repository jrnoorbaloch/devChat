Frequently asked questions

What is devChat?

devChat is an open-source chatbot SDK for TypeScript and Node.js. It gives you one API for several messengers, plus built-in commands, auto-replies and rate limiting.

Which messengers are supported?

npm run setup sets up WeChat and WhatsApp. Other drivers, such as remote puppet services, can be selected with DEVCHAT_PUPPET.

Can one bot run on WeChat and WhatsApp at the same time?

Yes. Choose "Both" in setup. startDevChat() starts one bot per messenger and runs your same setup code on each. If one messenger fails, the other keeps running.

Which Node.js version do I need?

Node.js 26 or newer, with npm 10 or newer. The installer checks this and helps you install it.

Can my account get banned?

Yes, it is possible. WhatsApp support uses WhatsApp Web, not the official WhatsApp Business API, and WeChat support uses the web protocol. Both messengers may restrict automated accounts. Use a separate test number, keep the built-in rate limits on, and never mass-message people.

How do I test a bot without a phone?

Use the mock driver that devChat's own tests use:

import { PuppetMock } from 'wechaty-puppet-mock'

const puppet = new PuppetMock()
const bot    = DevChatBuilder.build({ puppet })
const me     = puppet.mocker.createContact({ name: 'Bot' })
const user   = puppet.mocker.createContact({ name: 'User' })

await bot.start()
await puppet.mocker.login(me)
user.say('/ping').to(me)   // your handlers receive this message

Issues and pull requests are welcome on GitHub. Run npm test before opening a PR.
